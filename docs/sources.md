## Project research

1. Team-provided `references/Document1.pdf`, the supplied Thai ALSEP research document. Treat it as a starting brief and check scientific claims against primary sources.
2. NASA, [The Apollo Lunar Surface Journal and Apollo Flight Journal](https://www.nasa.gov/history/alsj-and-afj/).
3. Hamish Lindsay, [ALSEP: Apollo Lunar Surface Experiments Package](https://www.nasa.gov/wp-content/uploads/static/history/alsj/HamishALSEP.html), hosted by NASA. Instrument descriptions, deployment history, shutdown and experiment limitations.
4. NASA, [Lunar Surface Experiments](https://www.nasa.gov/wp-content/uploads/static/history/SP-4029/Apollo_18-33_Lunar_Surface_Experiments.htm), Apollo by the Numbers.

6. NASA Goddard, [Lunar Laser Ranging](https://science.gsfc.nasa.gov/solarsystem/planetarysystems/projects/605/).
7. NASA NTRS, [Lunar Gravitational-wave Detection](https://ntrs.nasa.gov/citations/20210025418). Limitations of the original Apollo 17 gravimeter experiment.
8. [Abandoned but not Forgotten challenge link supplied by the user](https://www.spaceappschallenge.org/2026/challenges/nasas-discarded-equipment-storytelling/). ## Fonts

These actual font files were retrieved from the Google Fonts source repository. Each bundled family includes its original SIL Open Font License text. WOFF2 files are web-format encodings of the bundled TTF files.

- [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk), Florian Karsten and the credited upstream authors.
- [Noto Sans Thai](https://github.com/google/fonts/tree/main/ofl/notosansthai), The Noto Project Authors.
- [IBM Plex Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono), IBM and the credited project authors.

The generated design mockup did not specify an exact typeface. Space Grotesk is the implementation choice, with a custom metallic finish in CSS and SVG. Keep the original font copyright notices and licenses. Font licenses apply to font software, not to the website's content as a whole.

## Artwork and UI references

- 18 PNGs are conceptual illustrations made with the built-in image-generation tool. ASE and LSPE are authored vector illustrations, also exported to PNG. The image generator rejected both seismic equipment groups, so vector illustrations cover those entries. None of these assets are NASA photographs or measured technical reconstructions.
- SVG branding, icons, overlays and CSS were authored for this asset pack. The project emblem is an independent orbital design.
- The 4 supplied visual inspirations in the conversation were NOVA, A-Space, a NASA-style website and Mars One. The user also supplied the project sketch. They informed the previous UI concepts; their original website images are not being supplied as reusable site assets.
- `references/01-landing.png` through `04-credits.png` are the earlier AI-generated UI concepts. These are opaque reference screenshots, not transparent cutouts.

Suggested credits copy: “Independent educational project. Concept visuals generated with AI. Historical research references: NASA and the Apollo journals. Instrument narration is fictionalized and labeled. No NASA endorsement implied.”

The completed website should attach citations to specific historical claims, preserve uncertainty where appropriate, and add any licenses/credits for later 3D models, real photography, map tiles or audio.
